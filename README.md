# آرشیو RTM — ژورنال‌های معامله‌گری

آرشیو استاتیک و فارسیِ ژورنال‌های معامله‌گری، با خواندنِ دوزبانه و تختهٔ یادداشت روی نمودار.

## چرا تصاویر کامل در Git نیستند؟

تصاویر کاملِ نمودارها حدود ۹۰۰ مگابایت‌اند و در Git نگه داشته نمی‌شوند. بستهٔ اصلی در **Release** همین مخزن با نام `assets-v1` است و بستهٔ کوچک تکمیلی (`assets-delta-v2.tar.gz`، تصاویر تازهٔ ژورنال Jurij) کنار همین فایل‌ها در مخزن است. اسکریپت، هر دو را در `site/assets` باز می‌کند. کیفیت تصاویر دست‌نخورده می‌ماند — فشرده‌سازی تا زیر ۱۰۰ مگابایت، متنِ نمودارها را ناخوانا می‌کرد.

مخزن شامل کد، داده‌ها (پست‌ها، جستجو، ژورنال‌ها) و فونت‌های محلی است؛ یعنی همه‌چیز به‌جز تصاویر.

## اجرا روی کامپیوتر خودتان

پیش‌نیاز: Node.js 18+ و `tar` (در ویندوز ۱۰ و بالاتر هست).

```bash
git clone https://github.com/Biootak/rtm-journals.git
cd rtm-journals
node scripts/fetch-assets.mjs     # یک‌بار؛ ~۹۰۰ مگابایت دانلود و استخراج در site/assets
npx serve site
```

سپس آدرس داده‌شده (معمولاً `http://localhost:3000`) را باز کنید.

- اسکریپت فایل را در `.assets-cache/` نگه می‌دارد؛ اجرای دوباره دانلود نمی‌کند.
- با `--force` دانلود و استخراج از نو انجام می‌شود.
- SHA-256 فایل در اسکریپت ثبت شده و بررسی می‌شود.

## انتشار روی Cloudflare Pages (پیشنهادی)

بعد از گرفتن تصاویر:

```bash
npx wrangler pages deploy site --project-name rtm-journals
```

سقف Cloudflare Pages: هر فایل ۲۵ مگابایت و ۲۰٬۰۰۰ فایل. این آرشیو ۱۳٬۶۳۰ فایل و بزرگ‌ترین فایل ~۱۲٫۸ مگابایت است، پس جا می‌شود.

## انتشار روی GitHub Pages

1. در Settings → Pages → Build and deployment، منبع را **GitHub Actions** بگذارید.
2. اکشن `.github/workflows/pages.yml` خودش تصاویر را دانلود می‌کند، `site/` را می‌سازد و منتشر می‌کند.
3. آدرس: `https://<username>.github.io/<repo>/`

> سقف حجم سایت در GitHub Pages یک گیگابایت است و این آرشیو نزدیک همان حد است؛ Cloudflare Pages جای مطمئن‌تری است.

## یادداشت‌ها

- یادداشت‌های روی نمودار در همان مرورگرِ بازدیدکننده (IndexedDB) ذخیره می‌شوند و به جایی فرستاده نمی‌شوند.
- پشتیبان‌گیری و کپیِ کنار تصویر از خودِ رابط انجام می‌شود.
- مسیریابی سایت بر پایهٔ hash است، پس بدون تنظیم بازنویسی مسیرها روی هر هاست استاتیکی کار می‌کند.
- محتوای ژورنال‌ها متعلق به نویسندگان اصلی است؛ این آرشیو فقط خواندنی و غیرتجاری است.

## ساختار

```
site/
  index.html
  css/            استایل‌ها
  js/             app.js، annotate.js، vendor/perfect-freehand.js
  data/           ایندکس، پست‌ها، جستجو، ژورنال‌ها و integrity
  assets/
    fonts/        فونت‌های محلی
    images/       تصاویر کامل (از Release، بعد از fetch-assets)
    thumbs/       بندانگشتی‌ها (از Release، بعد از fetch-assets)
scripts/
  fetch-assets.mjs
```
