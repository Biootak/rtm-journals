# آرشیو RTM — ژورنال‌های معامله‌گری

آرشیو استاتیک و فارسیِ ژورنال‌های معامله‌گری، با خواندنِ دوزبانه و تختهٔ یادداشت روی نمودار.

این مخزن **فقط چیزی را دارد که برای بالا آوردن سایت لازم است**: کل پوشهٔ `site/` (HTML، CSS، JS، فونت‌ها، داده‌های ساخته‌شده و تصاویر). هیچ سرور، پایگاه‌داده یا مرحلهٔ بیلدی لازم نیست؛ کافی است پوشهٔ `site/` سرو شود.

## اجرا روی کامپیوتر خودتان

```bash
npx serve site
# یا
npx http-server site -p 5173
```

سپس `http://localhost:3000` (یا پورتی که ابزار می‌گوید) را باز کنید. باز کردن مستقیم `site/index.html` با `file://` هم تا حد زیادی کار می‌کند، ولی سرو کردن آن مطمئن‌تر است.

## انتشار روی Cloudflare Pages (پیشنهادی)

رایگان، بدون سقف پهنای باند، مناسب سایت ۹۵۰ مگابایتی:

```bash
npx wrangler pages deploy site --project-name rtm-journals
```

یا از پنل Cloudflare → Workers & Pages → Create → Pages → Upload assets و پوشهٔ `site` را بارگذاری کنید.

## انتشار روی GitHub Pages

1. در Settings → Pages → Build and deployment، منبع را **GitHub Actions** بگذارید.
2. اکشنِ آمادهٔ `.github/workflows/pages.yml` با هر پوش روی `main` پوشهٔ `site/` را منتشر می‌کند.
3. آدرس: `https://<username>.github.io/<repo>/`

> توجه: سقف حجم سایت در GitHub Pages یک گیگابایت است و این آرشیو نزدیک همان حد است؛ اگر انتشار با خطا روبه‌رو شد، Cloudflare Pages جای مطمئن‌تری است.

## یادداشت‌ها

- یادداشت‌های روی نمودار در همان مرورگرِ بازدیدکننده (IndexedDB) ذخیره می‌شوند و به جایی فرستاده نمی‌شوند.
- پشتیبان‌گیری و کپیِ کنار تصویر از خودِ رابط انجام می‌شود.
- مسیریابی سایت بر پایهٔ hash است، پس بدون تنظیم بازنویسی مسیرها روی هر هاست استاتیکی کار می‌کند.

## ساختار

```
site/
  index.html
  css/            استایل‌ها
  js/             app.js، annotate.js، vendor/perfect-freehand.js
  data/           ایندکس، پست‌ها، جستجو، ژورنال‌ها و integrity
  assets/         تصاویر، بندانگشتی‌ها و فونت‌های محلی
```
