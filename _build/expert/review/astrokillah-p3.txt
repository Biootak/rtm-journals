following rules of drawing FL, i.e. combining the classical RTM
definition and also what's proposed by Salivan.

The classical definition calls for a TG to be hit before we can draw FL,
 however, at times, there is no TG in sight, that's when Salivan's
definition comes in handy. I will also include DP in my chart, because
at this moment, I have not been able to figure out how to use FL to
explain all the price movement, so if someone could point to me how to
do without DP, I would be extremely grateful.

First up is the EURCAD chart, the objective is to draw FLs from Monthly
down to H1 so I can use the charts to plan a trade. I start with an
FXTOP chart from 1953 to 1986:

Point 1: Price established a range between the two outer green horizontal lines

Point 2: The upper horizontal line was engulfed, so a signal from ITs that they want price higher.

Point 3: Deepest retracement. I can't really see why price turned at
point 3, not at this scale. I was hoping that price bounced from FL-A,
so I could explain the bounce using the concept of FL but unfortunately
this didn't happen.

Point 4: Price got near the upper limit of broken range, flagged, and
then rallied strongly, making ATH (All Time High). I drew a rectangle
-B, is this a DP or a FL? By definition, B looked more like a DP. It is
not easy for price to make ATH, so B has to be a very strong and
important level. After price left Point 4, we could draw an FL from
Point 2 to Point 3 (orange rectangle), but this is a huge FL, it's
probably too big to be useful?

Point 5: Price returned to B and bounced.

Point 6: Price engulfed previous high, so RTM theory says, if price ever
 return to B again, that will be a safe location to go long.

Point 7: RTM theory is proven right, B indeed held and turned price again.

Point 8: Price broke ATH again, I drew rectangle C around a big kink,
but because it has not held price, according to our definition, this is
an FTR.

Point 9: Another 'kink was created, and it held price, so D is an FL

Point 10: E is a DP that engulfed FL-D

Point 11: F is an FL that engulfed FL-C

Point 12: G is an FL that engulfed B

Point 13: H is an FL that engulfed A.

That's all I have until 1986, there are lots of small kinks, but they
didn't seem to have broken any important levels on this time scale, so I
 don't know what to make of them.

Any feedback/correction, is greatly appreciated.

DP را هم در نمودارم می‌آورم، چون در این لحظه نتوانسته‌ام بفهمم چطور با FL تمام حرکات قیمت را توضیح بدهم؛ پس اگر کسی بتواند نشانم دهد چطور بدون DP این کار را بکنم، بی‌نهایت ممنون می‌شوم.

اول نمودار EURCAD است؛ هدف رسم FLها از ماهانه تا H1 است تا بتوانم با نمودارها پلن معامله بچینم. با نمودار FXTOP از 1953 تا 1986 شروع می‌کنم:

نقطهٔ 1: قیمت بین دو خط افقی سبز بیرونی یک محدوده ساخت

نقطهٔ 2: خط افقی بالایی اینگالف شد، یعنی سیگنالی از ITها که قیمت بالاتر را می‌خواهند.

نقطهٔ 3: عمیق‌ترین اصلاح. در این مقیاس واقعاً نمی‌بینم چرا قیمت در نقطهٔ 3 چرخید. امیدوار بودم قیمت از FL-A بازگشت کند تا بتوانم آن بازگشت را با مفهوم FL توضیح دهم، ولی متأسفانه این‌طور نشد.

نقطهٔ 4: قیمت به سقف محدودهٔ شکسته‌شده نزدیک شد، فلگ زد و بعد قوی رشد کرد و ATH (بالاترین سقف تاریخی) ساخت. مستطیل B را رسم کردم؛ این DP است یا FL؟ طبق تعریف، B بیشتر شبیه DP بود. ساختن ATH برای قیمت آسان نیست، پس B باید سطحی خیلی قوی و مهم باشد. بعد از این‌که قیمت نقطهٔ 4 را ترک کرد، می‌توانستیم از نقطهٔ 2 تا نقطهٔ 3 یک FL رسم کنیم (مستطیل نارنجی)، ولی این FL عظیمی است؛ احتمالاً برای استفاده خیلی بزرگ است؟

نقطهٔ 5: قیمت به B برگشت و بازگشت کرد.

نقطهٔ 6: قیمت سقف قبلی را اینگالف کرد، پس نظریهٔ RTM می‌گوید اگر قیمت دوباره به B برگردد، آن‌جا محل امنی برای خرید است.

نقطهٔ 7: نظریهٔ RTM درست از آب درآمد؛ B واقعاً نگه داشت و دوباره قیمت را چرخاند.

نقطهٔ 8: قیمت دوباره ATH را شکست. مستطیل C را دور یک کینک بزرگ رسم کردم، ولی چون قیمت را نگه نداشته، طبق تعریف ما این یک FTR است.

نقطهٔ 9: کینک دیگری ساخته شد و قیمت را نگه داشت، پس D یک FL است

نقطهٔ 10: E یک DP است که FL-D را اینگالف کرد

نقطهٔ 11: F یک FL است که FL-C را اینگالف کرد

نقطهٔ 12: G یک FL است که B را اینگالف کرد

نقطهٔ 13: H یک FL است که A را اینگالف کرد.
