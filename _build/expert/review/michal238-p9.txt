naascott

There are few things I want to see when I'm looking for good DP:

- it can be located on swap zone

- FO zone can be created below it ( short scenario)

- also I like to see CP above strong DP - if price is compressed above,
then it is more likely that price will be reversed on this DP - it is
only fresh DP in the area

DP is a barrier to ITs, because another sellers are waiting on this
level (short scenario), so they need to do their manipulations before
price reaches it - they need to create LQ and when they do that we see
reversal patterns, FO zones etc.

bobyv87

FL and PAZ between them work in every TF, therefore some FLs are more
important than others, smaller or bigger FLs. There are diffrent
cycles.

It's quite difficult to learn spot all of this correctly but with a lot
of practice it will become clear. And don't forget to look left:

Markers are usually small FLs - ITs use them to reverse price before DP.
 I like to see when price bouces from this level few times - it creates
FO zone below DP which provides LQ for ITs. I enter on FO to DP after
confirmation - in this case it was eng into CPPAZ on approach. I thik
that after this reversal PA SL can be above DP (grey box - because it is
 FL in itself - you can see this on m1 chart). But if situation is not
very clear then you may use wider SL.
