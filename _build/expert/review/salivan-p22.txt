### salivan_p22_14
EN: Lately I had a man-cold, and for a while during that time I'd open the chart and feel I had no idea what I was looking at.

I knew I knew the market, but there was still something inside me telling me that I wouldn't be able to read it

This wasn't upsetting at all , because I knew full well this malady would pass and I'd be back on top of it again.

This can happen to anybody, due to illness, fatigue, fear of failure, fear of success, or any number of other causes.

For a student this can be very distressing and debilitating.

But it need not be terminal. The problem is not that one's read has
gone. The loss of the read is just a manifestation of another problem in
 life.

That's why, when we lose it, we must step away from the charts, and look within ourselves to find the unresolved issues.

Once we've faced and fixed them, we can get straight back to work in a
better state than if we never had the problem in the first place

I remember when I was learning the market, I'd have these EUREKA moments, which were wonderful!

I'd think to myself "I've got it! I've got it!" and imagine that now everything I did would be perfect from then on.

But it wasn't. I'd still not be right all the time. Soon I'd get another eureka moment, and think I had it again. But no.

There are a number of lessons which need to be learned, and each helps.
After all these lessons are learned, it still takes time for them all to
 fit together.

Once they do all come together, we don't think "EUREKA". Instead we sigh, and say "I'm ready".

IFMYANTE

ps.RTM not only taught me the market's behavior but also the life's behavior
