قوانین به‌روزشده:

شمارش ما با ظاهر شدن کندل Start Point (SP) شروع می‌شود. کندل Start Point باید: (1) کفی پایین‌تر از کف‌های 3 interval قبلی داشته باشد. (2) lower shadow بلند کندل Start Point (SP) باید از ترکیب upper shadow و بدنه‌اش بزرگ‌تر باشد. (3) Start Point باید 1-3 interval بعد از ظاهر شدن WRB بیاید. (4) lower shadow بلند کندل SP باید از هر دو lower shadow و بدنه‌های 3 interval قبل از WRB بزرگ‌تر باشد. این # ماست.

Confirmation کندل (CC) باید: (1) بالاتر از بدنهٔ کندل قبلی بسته شود. (2) بدنه‌ای بزرگ‌تر از بدنهٔ کندل قبلی داشته باشد. در دنبالهٔ 5 کندلی ما، CC باید #1، 2، 3 یا 4 باشد

بعد از اینکه Confirmation کندل داریم، قیمت باید به داخل lower shadow بلندِ کندل Start برگردد تا دنباله را اعتبارسنجی کند و ورود را فعال کند.

شمارش قرمز برای ترید شورت است. این شمارش پیشرفت کندل‌ها را شامل می‌شود.

متوجه شو کندل CC #3 است نه #2. این ترید گرفته نمی‌شد چون داخل یک SupplyDemand Delta ناحیه هستیم.
