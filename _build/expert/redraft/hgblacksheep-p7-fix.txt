در این شماتیک، کشیده‌ام که یک ترتیب پیش‌روندهٔ Start Point می‌تواند چه شکلی باشد.

بعد از WRB، اولین Start Point ما را داریم. یک Start Point باید سقف بالاتری از interval قبلی بسازد و upper shadow باید از ترکیب lower shadow و بدنه‌اش بزرگ‌تر باشد. این کندلی است که شمارشمان را روی آن شروع می‌کنیم. کندل بعدی باید تغییر احتمالی در داینامیک Supply/Demand را که کندل Start ما نشان می‌دهد تأیید کند.

در این مورد، کندل بعدی 1A را تأیید نمی‌کند. ولی از نظر تعریف خودش یک Start Point دیگر است. پس شمارشمان را از نو شروع می‌کنیم. می‌توانیم تا وقتی Start Point‌های متوالی می‌گیریم شمارش را ری‌استارت کنیم. توجه کن در 1D حالا بیش از 3 interval بعد از WRB هستیم. چون Start Point اولیه داخل شرط 1-3 interval بود، می‌توانیم ادامه دهیم.
