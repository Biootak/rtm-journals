# Professional translation status

## Audit classifier fixed — 2026-11-13

`audit-quality.js` was over-reporting two classes, which inflated the quality
queue to 2,200 posts / 800 pages and would have sent whole pages back for
retranslation to chase noise:

- **no-verb** used a fixed verb list that missed ordinary Persian forms
  («می‌شوم», «می‌فروشیم», «داشته باشید», «می‌مانم», «ساخت»). A nominal Persian
  sentence is also grammatical. It is now computed for information only and
  never gates a page (1,414 hints, 0 defects).
- **english-left** matched any single dictionary word, so handles («whiteout»),
  jargon («high», «can-can»), URLs and pattern names were flagged. It now
  requires a run of **three or more** Latin words containing a lowercase
  English word — actual unfinished-translation residue.

Honest backlog after the fix: **393 posts on 263 pages**
(english-left 180, fragment 164, calque 50, untranslated 5, omission 1).
Findings are written to `_build/expert/quality-findings.json`.

## Automation — no user reminder needed

- `_build/expert/WAVE.json` names the current wave and its expected batch files.
- `.qoder/settings.local.json` registers a `Stop` hook with `asyncRewake` that
  runs `_build/expert/wave-watch.js`; it polls the batch files and, when the
  wave is complete and the validator is clean, exits 2 with `WAVE READY` so
  Qoder wakes the model to publish and launch the next wave. Rejections produce
  `WAVE BLOCKED` with the failing ids instead.
- A `UserPromptSubmit` hook (`wave-context.js`) injects the same reminder on the
  next prompt if the background watcher was lost (restart or timeout).
- Every wake is appended to `_build/expert/WAVE-LOG.md`; a fresh
  `.wave-watch.heartbeat` means a watcher is alive. If the hook never fires,
  open Settings → Hooks once to refresh the config.
- After 20 minutes without a new completed batch the watcher reports
  `WAVE STALLED` with the missing files, so a dead subagent cannot stall the
  whole wave silently.
- Cap concurrent subagents at **6**: the 12-agent IF p41–123 wave lost every
  agent to Qoder's internal error around the 17-minute mark. 25 pages had
  already been written and validated; the remaining 58 are being retried in
  6-agent groups.

## Workflow

```bash
# 1. create work files for the next pages
node _build/expert/workflow.js --journal if --pages 13-19

# 2. translate each work file into _build/expert/batches/if-p13.json …

# 3. quality gate for every batch
node _build/expert/workflow.js --validate

# 4. publish
node _build/bake-translations.js && node _build/build-site.js

# 5. global QA report
node _build/expert/qa-translations.js
```

`workflow.js --validate` rejects a batch on paragraph-count mismatch, a missing
price/R multiple, a quote head without `نوشت:`, or any lexicon defect.
`qa-translations.js` audits the whole shipped layer and writes
`_build/expert/qa-report.md`.
