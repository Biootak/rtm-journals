# Font licenses

The bundled `.woff2` files are subsets of the following open-source families.
All three are licensed under the **SIL Open Font License, Version 1.1**
(<https://openfontlicense.org/open-font-license-official-text/>), which permits
bundling, subsetting and redistribution, provided the fonts are not sold on
their own and any derivative keeps a different name.

| File | Family | Author / source |
|---|---|---|
| `vazirmatn-arabic.woff2`, `vazirmatn-latin.woff2` | Vazirmatn | Saber Rastikerdar — <https://github.com/rastikerdar/vazirmatn> |
| `newsreader-latin.woff2`, `newsreader-latin-italic.woff2` | Newsreader | Production Type — <https://fonts.google.com/specimen/Newsreader> |
| `jbmono-latin.woff2` (served as `RTM Mono`) | JetBrains Mono | JetBrains — <https://www.jetbrains.com/lp/mono/> |

No modifications were made other than unicode-range subsetting performed at
download time. The full OFL text ships with each upstream release and is
reproduced in the repositories linked above.
